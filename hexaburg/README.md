# ヘキサブルグ (hexaburg)

六角形のマスを広げ、相手のセルを狙って壊し合いながら、つながった一番大きなかたまりを競う陣取りゲームです。手番はなく、全員がいつでも行動できるリアルタイム対戦です。2〜12人でオンライン対戦できます。

- [ヘキサゴニア](../hexagonia/) をもとに、ルールをいちど最小限まで削って作り直しています（リスクとリターン、ストレスと解消を念頭に、ここから足していく）
- オンライン対戦は [PeerJS](https://peerjs.com/)（WebRTC の P2P）を使います。部屋を作った人（ホスト）のブラウザがゲームを進め、サーバーはいりません
- 部屋の空いた席に CPU を入れられます。「CPUと遊ぶ」なら、ひとりで通信なしでも遊べます
- ビルドは不要です。素の HTML・CSS・JavaScript だけでできています

---

## 遊び方

1. ホストが名前を入れて「部屋を作る」を押し、「部屋ID」か「招待URL」をほかの人に送る
2. 参加する人は招待URLを開くか、部屋IDを入れて「参加する」を押す
3. ロビーで陣営色を選ぶ。人数が足りなければ、ホストが「＋ CPUを追加」で CPU を入れる
4. 必要なら、ホストが「盤面の大きさ（直径）」と「ターン数」を選び、「ゲーム開始」を押す

手元で試すときは、リポジトリのルートで `python3 -m http.server` などを動かして `http://localhost:8000/hexaburg/` を開いてください。GitHub Pages で公開した場合は、サイトの URL の後ろに `hexaburg/` を付けた URL がゲームのページです。

- **ホストはゲームが終わるまでページを閉じたり再読み込みしたりしないでください**（部屋が終わります）
- ホスト以外の人は、接続が切れても同じブラウザで招待URLを開き直せば、同じプレイヤーとして戻れます

## ルール

ゲームの中の「ルール」（トップ・ロビー・ゲーム中の「？」）でも、図つきで説明しています。

- 盤面は大きな六角形で、**すべて平原**です（地形・河川はありません）。大きさは人数に合わせて決まります（2〜3人：直径9／4人：11／5〜6人：13／7〜8人：15／9〜12人：17）。ロビーで直径 7〜21マスから選ぶこともできます
- 各プレイヤーのコアは、6人までは盤面の一番外側に等間隔に置かれます。7人以上は約3分の1のコアを内側の輪に置きます
- 全員、資源10・戦力3・行動力3・コアの1マスから始めます
- 手番はなく、**いつでも行動できます**。ゲーム開始の前に 3・2・1 のカウントダウンがあります
- **拡張**：自分のセルの隣の空きマスに、資源1と行動力1で自分のセルを置きます。相手のセルには置けません
- **発展**：コア以外の自分のセルを、資源3と行動力1で、**鉱山**（◆。ターンごとに資源 +2）か**工場**（□。ターンごとに戦力 +2）にします。壊されると発展もなくなります
- **体力**：セル（コアも）の体力は6で、縁の内側の少し透けた帯で全員に見えます（体力1つにつき辺1本ぶん）。0 になると壊れて空きマスに戻ります
- **狙い**：自分のセルの中心から、隣の相手のセルまでドラッグして離すと、そのセルを狙います（狙いを変えるときも同じ。セルのふちのほうからドラッグすると盤面が動きます）。狙いは弧を描く矢印で全員に見えます。セルにカーソルを乗せると、そのセルに向いている矢印が動いて光ります。行動力は使いません。**ひとつのセルの狙いは1ターンに1回しか決めたり変えたり（外したり）できません**
- **攻撃**：狙っている相手のセルを選んで「攻撃」。そのセルを狙っている自分のセルの数を n（1〜6）とすると、**戦力 7−n で体力を n 減らします**（行動力1）。狙うマスを集めるほど、安く強くなります
- **反撃**：狙われている自分のセルを選んで「反撃」。狙ってきている相手のセルが k マスなら、**戦力 2k で、その全部の体力を k 減らします**（例：3マスに狙われていたら、戦力6で3マスとも −3。行動力1）。たくさん狙われるほど危ないけれど、反撃も大きくなります
- コアが壊れた人は脱落し、残りのセルは空きマスに戻ります。資源と戦力は、壊した人が受け継ぎます
- **行動力**は5秒に1回復します（最大5）。拡張・発展・攻撃・反撃で1使います（狙いは使いません）
- **30秒ごとの「ターン」**で、全員いっせいに資源（コア +2・鉱山1つにつき +2）と戦力（+3・工場1つにつき +2）を受け取ります
- **行動完了**：下のバーの「行動完了」を押すと、このターンはもう行動しないという印がつきます（もう一度押すと取り消し）。生きているプレイヤー全員が押したら、30秒を待たずに次のターンへ進みます。飛ばした時間のぶん、行動力の回復も秒単位で進みます
  - もうできる行動（拡張・発展・攻撃・反撃）がないときは、自動で行動完了になります（自分で外したターンは除く）
  - CPU は、やりたい行動がもうないと判断したときに行動完了になります。切断中の人は押したものとみなします
- 決まった回数のターン（4人まで18回＝9分・8人まで16回＝8分・12人まで14回＝7分。ロビーで10〜30回から選べる）が終わったら、勝敗を決めます
- **終了時の数え上げ**：かたまりが小さい人から順に、一番大きなかたまりを1マスずつ数え上げ（音つき）、最後に勝った人を光らせてから結果を出します
- **つながっている一番大きなかたまり**が一番大きい人の勝ち（同じなら同率優勝）。プレイヤー一覧の「⬡ 9/12」は「一番大きなかたまり 9 ／ セルの総数 12」です
- 切断したまま戻らない人は、ホストがプレイヤー一覧の「脱落させる」で脱落させられます（セルは空きマスに戻ります）

## 開発者向けメモ

| ファイル | 中身 |
| --- | --- |
| `shared/engine.js` | ルール（盤面の生成・行動の検証と実行・ターンの処理・勝敗）。数値は先頭の `RULES` |
| `shared/cpu.js` | CPU の考え方（拡張・発展・狙い・攻撃・反撃に点数を付けて選ぶ。狙いは集中させ、壊せるときや多く狙われたときに攻撃・反撃する） |
| `shared/room.js` | 部屋（ロビー・ゲーム開始・カウントダウン・ターンと行動力のタイマー・行動完了・CPU の進行・切断） |
| `board.js` | 盤面の描画（canvas）と操作。体力の帯・狙いの矢印・終了時の数え上げで塗るマスもここ |
| `client.js` | 画面と通信（PeerJS）。終了時の数え上げの進行もここ |
| `sound.js` | 効果音（Web Audio で合成） |
| `index.html` / `style.css` | 画面（ルールの動く図は SVG と CSS アニメーション） |
| `test/` | テスト（`npm test`。Node.js 18 以上） |

- ホスト権威型です。参加者は行動の要求をホストへ送り、ホストが `engine.js` で確かめてから状態を更新し、全員に配信します
- `Room` は30秒ごとに `rtTick`、5秒ごとに `rtRegen` を呼びます。CPU はそれぞれ1.5〜3.5秒のばらつきのある間隔で考えます
- 部屋の ID の頭は `hexaburg-v1-` です（ヘキサゴニアの部屋とは混ざりません）。ブラウザに保存する設定の名前は `hexaburg.` で始めます
- ファイルを更新したら、`index.html` の `?v=` の数字を上げてください（GitHub Pages のキャッシュ対策）

```
cd hexaburg
npm test
```

# Snowfield（スノーフィールド）

雪の極寒世界で資源を集め、寒さと空腹をしのいで生き延びる、**3〜16人の協力型サバイバルボードゲーム**です。
準備期間 → 最終猛吹雪を全員で生き延びればクリア（ラウンド数は人数で決まる。準備期間＝12−（人数÷3の切り上げ）、最終猛吹雪＝1〜4人:5・5〜8人:4・9〜12人:3・13〜16人:2）。**全員が行動不能**（8人以上は半数以上）になる、または**すべての焚き火が消えたまま3ラウンド**続くとゲームオーバーです。ラウンドは**全員が同時に**行動します（ロビーで「順番に動く」にも変えられます）。

- ブラウザを開くだけで遊べます（インストール・ビルド不要。素の HTML・CSS・JavaScript）
- オンライン対戦は [PeerJS](https://peerjs.com/)（WebRTC の P2P）。部屋を作った人（ホスト）のブラウザがゲームを進め、専用サーバーはいりません
- 「CPUと遊ぶ」なら、ひとりで通信なしでも遊べます。オンラインの部屋にもCPUを入れられます（人数は合計3〜16人）

## 遊び方

1. トップで名前を入れて「部屋を作る」を押し、「部屋ID」か「招待URL」をほかの人に送る
2. 参加する人は招待URLを開くか、部屋IDを入れて「参加する」を押す
3. ロビーで人数が足りなければ、ホストが「＋ CPUを追加」で CPU を入れる（3人以上で開始できる）
4. ホストが「ゲーム開始」を押す
5. 1人で試すなら「CPUと遊ぶ」を押す（CPU 2人が自動で入る。ロビーで増減できる）

手元で試すときは、リポジトリのルートで `python3 -m http.server` などを動かして `http://localhost:8000/snowfield/` を開いてください。GitHub Pages で公開した場合は、サイトの URL の後ろに `snowfield/` を付けた URL がゲームのページです。

- **ホストはゲームが終わるまでページを閉じたり再読み込みしたりしないでください**（部屋が終わります）
- ホスト以外の人は、接続が切れても同じブラウザで招待URLを開き直せば、同じプレイヤーとして戻れます
- 接続の仲立ち（シグナリング）には PeerJS の無料の公開サーバーを使います。社内ネットワークなど一部の環境では直接つながらないことがあります。自前の PeerServer を使うときは `client.js` 先頭の `P2P.peerOptions` を参照してください

### 操作

| 操作 | やり方 |
| --- | --- |
| 移動（行動力0・手番外でも可） | 自分の駒をドラッグして、行きたいマスで離す |
| 行動（温まる・焚べる・食べる・集める・攻撃・植える・直す・建てる） | 自分の駒をクリックしてメニューから選ぶ（手番のみ） |
| 建てる | メニューの「建てる」→ 左下の建設カードを盤面へドラッグ |
| 視点の移動・拡大縮小 | 背景をドラッグ／ホイール／右上のボタン |
| 食べる・着ける・捨てる投票 | 右の共有アイテムのアイコンをクリック → 出てくるボタンから選ぶ（捨てる投票は、全員が賛成／反対。過半数の賛成で1個捨てる） |
| 道をふさがれたとき | ドラッグして行けないとき（またはほかの人の駒をクリック）に出るボタンで、どいてもらうようお願いする（CPUはすぐに動く。人には確認が届く） |
| お絵かき（ゲーム効果なし） | 手番でないときに「お絵かきモード」。ペン・消しゴム・青／灰 |
| 手番（行動）を終える | 上のバーの「手番を終える」（同時に動くときは「行動を終える」） |

ゲームの中の「ルール」ボタン（項目ごとのページ）でも説明しています。初めてなら、トップの「チュートリアル」で、操作しながら基本を覚えられます。

## ルール（実装の要点）

仕様書（`snowfield-rules.md`）のとおりです。数値はすべて `shared/engine.js` 先頭の `RULES` にまとめてあり、調整できます。

- 体温・満腹度は最大10。自分の手番（行動）の終わりに：満腹度 −3 → 体温低下 → 行動不能の判定。ラウンドの終わりに：すべての焚き火の火力 −3（雨は −4）、動物・魚が2マス動く
- 体温低下：焚き火の上 0／防寒が有効な建物の中 −1／それ以外 −2。これに天候補正（雪+1・吹雪+2・猛吹雪+4）。防寒の中では補正を最大2軽減
- 行動力はラウンドの始め（順番なら手番の始め）に7。猛吹雪の間は、ラウンドの始めに建物（焚き火・道・橋を除く）のHPが2減る
- 移動できるのは建物（道を含む）から1マス以内。雪原に入るたび体温 −1。マップは建物の周囲8マスが生成される無限マップ
- 動物は**ラウンドの終わり**に2マスずつ動く
- 人数は3〜16人（`RULES.minPlayers` / `maxPlayers`）。形と色の組み合わせは、全員ちがう

### 仕様書にない補足（実装で決めたこと）

- **開始時の資源の保証**：移動できる範囲（焚き火から1マス以内）に資源が1つもないと、雪を得られず道も作れず詰んでしまうため、ゲーム開始時に範囲内へ最低限（木2・石1・野菜1。`RULES.startReach`）を置きます。それ以外のマップ生成は仕様どおり（各マス約10%）です
- 建物は、既存の建物（道を含む）に辺で隣接する場所にだけ建てられます（道の上に重ねて建てるのも隣接とみなす）
- 効果音は音声ファイルを使わず、Web Audio で物体の響きやノイズから作っています（`sound.js`。上のバーの「音」で消せる）
- 手番・ラウンドが変わったときは画面中央でお知らせし、行動力が0になったら手番終了をうながします
- 駒の形（丸・四角・ひし形・上向き／下向き三角形・六角形）と色（12色。ほかの人と同じ色は選べない）は、ロビーで選びます
- 資源・動物・苗の外側にある、ひと続きの線の区切り1つが、体力1（苗は育つまであと1ラウンド）です。動物以外は六角形、動物は円です
- 制限時間：同時に動くときはラウンドごとに120秒（`RULES.roundLimitMs`）、順番に動くときは人間の手番ごとに180秒（`RULES.turnLimitMs`）。人間がいるときだけで、切れると自動で終わります
- ゲーム開始時に、人数ぶんの野菜が配られます（`RULES.startVegPerPlayer`）
- 見張り台からは2マス以内に移動できます
- **料理と装備**：動物は毛皮（1〜5個）を落とします。焚き火の上かすぐ隣で「作る」と、肉1→ステーキ（満腹度+5）、野菜2＋雪1→スープ3個（満腹度+2）。作業場（2×2・屋外・木材3・壊れる）の上かすぐ隣で「作る」と、木材1→薪2、毛皮3→防寒着（手番の終わりの体温の低下−1）、木材1＋石材1＋毛皮1→斧・ツルハシ・シャベル（木・石・野菜を集める量+1）・槍（動物への攻撃力+1）、木材1＋石材3→弓（5マス以内の動物を攻撃できる）、木材1＋石材1→釣り竿（3マス以内の川の魚を攻撃できる）。
- **川と魚**：マップには、ゆるく曲がった太さ2マスほどの川が、縦か横にまっすぐ長く流れていて（40マスおきに1本。ゲームごとに向きが決まる。座標とシードだけで決まる）、雪原ではないので、橋がないと移動も建設もできません（焚き火の周り4マスには川はありません）。川にだけ「橋」（木材1・道と同じ仕様）を建てられ、橋の上にはほかの建物を建てて上書きできます。魚は人数ぶんいて、川の上だけを動きます（体力1〜3）。釣り竿を着けて3マス以内から攻撃し、倒すと魚1〜3個（満腹度+3。焚き火で魚1→焼き魚1にすると満腹度+5）。数値は `RULES.fish*` / `RULES.river*`「作る」は行動力1。装備は「装備」「道具」の枠が1つずつで、着けるのは行動力0・外すのは1。道具の耐久度は7（`RULES.toolDur`）
- 焚き火の一辺は「その焚き火で始まる人数÷1.5の切り上げ」（3人＝2×2、4人＝3×3、5人＝4×4。`RULES.fireDiv`）。8人以上（`RULES.twoFiresFrom`）は焚き火が2つになり、プレイヤーが交互に分かれて始まります（16人なら8人ずつ＝6×6）。火力は焚き火ごと。配布・資源の確率・動物・魚の数は、人数に比例して増えます
- 資源の比率は木3：石2：野菜2（`RULES.resWeights`）。動物以外の資源・動物・苗は丸で、これまでの約66%の大きさです
- 天候の抽選に猛吹雪は入っていません（猛吹雪は最終の3ラウンドだけ）
- 左下の「建てる」「作る」のボタンで一覧を切り替えます（建設しても閉じません）。カードをクリックで選ぶと、マップをクリックして続けて置けます。資源のあるマスにも建てられます（その資源は消えます）。雪も、上限で入らないときは、入れ替えか捨てるかを選びます
- ゲーム開始時に、人数ぶんの野菜と薪、雪3個が配られます（`RULES.startVegPerPlayer` / `startFirewoodPerPlayer` / `startSnow`）
- すべての焚き火が消えたまま（火力0）でラウンドが終わるのが3ラウンド連続すると敗北です（`RULES.fireOutLimit`）。火力1以上で手番を終えれば数え直しです（`RULES.startItems`）。プレイヤーは焚き火の下の段から始まります
- 行動不能のあいだは、自分の復帰手番も含めて「移動」できません（温まる・食べるだけ）
- 切断中の人の手番は、短い待ち時間のあと自動で終わります。「捨てる」投票では反対として扱います
- 手番の順番は参加順。行動不能の人の手番もスキップしません（復帰手番になる）

```bash
cd snowfield
npm test   # node --test test/*.test.js （依存パッケージなし。Node.js 18以上）
```

- テストはルール（体温低下・行動不能・猛吹雪・建設・投票・お絵かきなど）と、CPUだけの対戦が最後まで進むことを確かめます
- 更新したら `index.html` の `?v=` の数字を上げてください（GitHub Pages ではブラウザが古いファイルを使い回すため）
- CPU は、道を伸ばして移動の体温コストを減らし、火力を必要なぶんだけ焚べ、苗を育て、最終猛吹雪に備えて薪を貯めます。CPUだけでもクリアでき（目安：同時に動く設定で、3人で約50%、4人で約70%、8人で約90%、12人以上はほぼクリア。人数が多いほど有利）、人が入れば有利になります。焚き火が消えたまま3手番続くと負けるので、消えかけたら薪を焚べ、そのための薪を残します。猛吹雪では、倉庫（防寒施設）へ避難し、HPが2減ったら修理します。強さは `shared/cpu.js` 先頭の定数で調整できます


## バージョンと更新履歴
- いまのバージョンは `shared/engine.js` の `VERSION`（v3.0）。**違うバージョンの人とは遊べません**（参加するときにホストが確かめ、違うと「ページを再読み込みして最新版に」と案内します）
- 更新履歴は `changelog.js`（トップの「更新履歴」から読めます）。バージョンを変えるときは、`VERSION` を更新し、`changelog.js` の先頭に、今までの変化を簡潔にまとめて足してください（テストが、先頭の版が `VERSION` と同じことを確かめます）

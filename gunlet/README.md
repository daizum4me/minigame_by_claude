# 豆鉄砲 (gunlet)

7×7の交点盤で射撃を主体に戦う、2人用の盤上ゲーム。ブラウザで `index.html` を開くだけで遊べます（ビルド不要）。

- 二人対局 / CPU対戦（CPUを先手・後手どちらにも設定可）
- 駒を選ぶと移動先（点）と攻撃対象（枠）を表示
- 持ち駒（壁・塔）は盤の脇のボタンから選んで配置
- 「戻す」で一手戻す（CPU戦では自分の手番まで）

## 駒の表示

| 形 | 駒 |
| --- | --- |
| 二重丸 | 将 |
| 三角 | 弓兵 |
| 四角（中が抜けていれば未装填） | 銃兵 |
| 長丸 | 盾兵 |
| 灰色の四角 | 壁 |
| 大きな輪 | 塔 |

黒が先手、白が後手。駒の下の点は残り耐久。

## 試作ルールの未決定事項の扱い

- 将も塔に乗れる
- 塔の上の銃兵も壁は越えて撃てない（射程+1のみ）
- 射程上限は弓・銃とも3（塔の上で4）
- 初期配置はルールブックの叩き台どおり
- 200手で引き分け。手が無い側はパス

## ファイル

- `engine.js` — ルール（盤面・合法手・適用）
- `ai.js` — CPU（2手読み）
- `main.js` — 画面描画と操作
- `style.css` / `index.html`

# Cocage

幹から枝と葉を伸ばし、各列の「一番上の葉」で得点を競う、2〜5人用のヘックス盤ゲームです。全36ターン、合計点がいちばん高い人の勝ち。全員が同時に行動を決め、衝突したときだけ抽選で決着します（手番の待ち時間はありません）。

- 遊び方：`cocage/index.html` を開く（ビルド不要）。部屋を作って招待URLを送るか、「CPUと遊ぶ」でひとり遊びができます。
- 通信：PeerJS（WebRTC の P2P）。部屋を作った人のブラウザがホストになり、ゲームの進行と判定をします（ゲームが終わるまでページを閉じないでください）。CPU対戦は通信なしです。
- テスト：`cd cocage && npm test`（Node 18 以上）

## ルール

詳しくはゲーム内の「ルール」にもあります。

- **盤面**：18行のヘックス（頂点が左右のフラットトップ）。左右がつながった横ループで、列の数は 6 × 人数（12 / 18 / 24 / 30）。ホイールで拡大・縮小、ドラッグで移動できます（縦は拡大していなくても、上下に画面の高さの45%ぶんまで動かせます。ホイールでの左右の移動はありません。スマホはピンチと1本指のドラッグ。「全体」で元の大きさ）。
- **幹**：列 2+6i（隣の幹との間に通常の列がちょうど4列）の右のふちを、下から上へジグザグに伸びます。**最初から1辺伸びていて**、毎ターン自動で1辺ずつ伸び、18行目の頂点（全36辺）に着いて止まります（壊れません。着くのはターン35）。
- **1ターン**（これを36回）：
  1. 同時行動：全員が行動力3の範囲で行動を選ぶ（制限時間90秒）
  2. 幹の成長：全員の幹が1辺伸びる
  3. 折れ判定：すべての枝の辺について折れるかを抽選する
  4. 光合成：各列の得点を計算して加算する
- **枝**（行動力1）：自分の幹・枝の頂点から、辺に1本つなぐ。幹が通る予定の辺（全員ぶん）は予約済みで置けません。
- **葉**（行動力1）：自分の枝に接するセルに1枚置く。あとから動かせません。枝が折れて土台（自分の枝）がすべてなくなると、一緒に消えます。
- **行動力**は毎ターン全員3で、使い切らなくてかまいません（繰越しなし）。行動は1つずつ「確定」でき、全員が確定したら90秒を待たずに次へ進みます。時間になったら、その時点の内容でそのまま自動で確定します。確定の順番や時刻は勝敗に影響せず、ほかの人にも見えません（確定した人の数だけ分かります）。
- **衝突**：同じ辺・セルを複数人が選んだら等確率の抽選で1人だけが成功します。負けても行動力は戻りません。選んだ人が1人なら、確定の早遅に関係なく必ず成功します。
- **折れる確率**（毎ターン・辺ごと）：`p = 0.05% + 0.03% × 高さ + 0.05% × 支える枝の数`。高さ＝その辺の行番号、支える枝の数＝その辺とその先（子孫）の枝の数（先端の辺は1）。**根本ほど重さがかかって折れやすく**なります。折れると、その辺とその先の枝・葉がすべて消えます。折れた根元の頂点（まだ自分の幹・枝につながっている側）には**傷あと**が残り、持ち主はそこから**3ターン**枝を伸ばせません（ほかの人は置けます。盤面には残りターン数の輪で表示。`RULES.scarTurns`）。一本道の枝なら、全体の折れやすさは以前（長さで決まるルール）と同じで、長さ8・高さ9の先端の葉が10ターン生き残る確率は約65%です。枝分かれさせるほど根本が重くなります。
- **得点**：列で一番上の葉は `1 + min(3, その列の下にある他人の葉の数) + 0.1 × 行番号`（高さボーナス。1行目 +0.1〜18行目 +1.8。`RULES.score.height`）。ほかの葉は、その人の、その列で一番上の葉（上に他人の葉があるもの）だけが 0.3、同じ人の2枚目以降は 0。例（上から、高さボーナスを除く）A=2・B=0.3・A=0・A=0・A=0。

## 操作

- 今置けるところは**白く光ります**。光っている辺をクリックで枝、セルをクリックで葉（モードの切り替えはありません）。
- **右クリック**で行動を取り消せます（計画した行動の上なら、その行動。何もないところなら、いちばん新しい行動）。
- ホイールで拡大・縮小、ドラッグで移動。ツールチップは、枝にカーソルを合わせると出ます。

## 効果音

葉と枝の音をイメージして、WebAudio で作っています（音声ファイルなし）。電子音にならないように、ノイズの粒（葉のこすれる音）・木をたたく共鳴（コッ）・枝の折れる音（パキッ）・風を材料にして、鳴るたびに少しずつゆらぎます。

- 自分の操作：枝を置く（コッ）／葉を置く（くしゃっ）／置けない（にぶい音）／取り消し／確定／全て確定／残り10秒からの小枝のカチカチ
- ターンの解決：風が通る → 枝・葉が置かれる → 抽選に負ける → 幹がきしむ → 点数の葉が散る（点数が大きいほど明るく、木の音が混ざる）→ 一番上が入れ替わる → 数字がこぼれたあとに、枝が折れる（光る・パキッ・どすっ・かけらが落ちる・葉が散る）
- ゲーム開始・終了・勝ち・負け、接続が切れたとき
- 「🔊 音あり」ボタン（トップ・ロビー・ゲーム画面）でオン・オフ。設定はブラウザに覚えます。

## 見た目

暗い背景（`#1F1F1D`）に、六角形のセルと細い線だけで描きます。アニメーションは、点数を稼いだときに葉から数字が1つこぼれる演出と、そのあとに枝が折れる演出だけです（「視差効果を減らす」設定では出しません）。

- 台 `#2A2A28`（角丸16・14pxの余白）、セル 塗り `#3A3A38`・線 `#56554F`
- プレイヤー色：P1 `#6FB1F2`／P2 `#F2766D`／P3 `#7BD39A`／P4 `#B596EE`／P5 `#F2C46D`
- 幹と枝：セルの辺の上を通る太さ2.4の丸端の線。幹はプレイヤー色の明るい方（得点の数字と同じ色）、枝はプレイヤー色。次に伸びる幹は点線 1辺だけ
- 葉：セルの0.78倍の六角形（塗り不透明度0.45・線2）。そのターンに置いた葉は白い線。列の一番上の葉は0.67倍の六角形の輪つき。点数を稼いでいる葉すべてに、中央に点数（小さめの太字・自分の明るい色・縁なし）
- 折れた枝：数字がこぼれたあと、ぴかっと光ってかけらになって落ち、折れたところに赤い×と「折れた！」が出ます（一緒に消える葉は縮んで消えます）。そのあと、折れたターンのあいだは `#FF9C94`・太さ3の点線で残ります。抽選に負けた行動：プレイヤー色の×印
- 枝にカーソルを合わせると（弱いぼかしの半透明の台に）、折れる確率・内訳・10ターン残る確率・失うものを表示。「折れる確率」「期待損失」で、盤面全体の危険度を緑→黄→赤で一覧（幹は灰色）

## 仕様で決めきれていなかった点（仮置き）

- 葉を置けるのは「自分の**枝**に接するセル」とし、幹に接するだけのセルには置けません（`RULES.leafOnTrunk` を `true` にすると、自分の幹に接するセルにも置けるようになります。幹は折れないので、その葉も残ります）。
- 支える枝の数は、枝の数だけを数えます（葉は数えません）。一本道なら、仕様の例（長さ8・高さ9で約65%）と一致します。
- 辺の高さは、辺の中点の高さから決めます（幹は 1,1,2,2,…,18,18 行目）。
- 同じ人の枝が両端とも自分の幹・枝につながる辺（輪になる辺）は置けません。
- 同じターンに計画した枝には、続けて枝・葉をつなげられます（前の行動が抽選に負けたら、あとの行動も失敗します）。
- 切断中の人は、そのときの計画のまま確定したものとみなします。5人目の色（P5）は仕様にないので `#F2C46D` にしました。
- ツールチップの枠は、仕様の2か所（白の不透明度0.12／`#56554F`）のうち、盤面とそろえる `#56554F` にしました。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `shared/engine.js` | ルール（盤面の形・計画の検証・同時解決・折れ判定・得点）。数値は先頭の `RULES` |
| `shared/cpu.js` | CPU の考え方（葉は列の得点の増減と相手から奪う点、枝はその先に置ける葉の価値・もう1辺先で相手の一番上を覆えるか・根本の重さを込みの折れやすさで点をつける） |
| `shared/room.js` | 部屋（ロビー・90秒のタイマー・全員確定で次へ・CPU の進行・ほかの人の計画を伏せる・切断） |

| `client.js` | 画面・通信（PeerJS）・得点パネル・推移グラフ・ツールチップ |

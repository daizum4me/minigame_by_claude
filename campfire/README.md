# 焚き火の夜 (campfire)

真冬の夜、遭難した旅人たちがひとつの焚き火を囲んで夜明けを待つ対戦型ボードゲーム。
あなた1人＋CPU 2〜4人で遊びます。ブラウザで `index.html` を開くだけで遊べます（単一ファイル・ビルド不要・外部ライブラリなし）。

## 遊び方

- 開始画面で人数（3〜5人）とCPUの速さを選んで「はじめる」
- 自分の手番では行動を1つ選ぶ。カードを押すと使える行動ボタンが光り、もう一度押すと実行
- 「くべる」を押して燃料が複数種類ある場合は、くべるカードを選ぶ
- 凍死したあとは「結果まで早送り」で最後まで飛ばせる

## 実装メモ

- ルールの数値はすべて `<script>` 冒頭の `CONFIG` にまとめてある
- 乱数はシード指定可能：`index.html?seed=123`（最初の1ゲームに適用。シードはコンソールにも出力）
- `window.campfire` からルールエンジン（`createGame` / `doAction` / `cpuChoose` など）を呼べるので、CPU同士の自動対戦シミュレーションができる

## 仕様書で決まっていなかった点の扱い

- 最初のスタートプレイヤーはランダム
- 飲んだスープは捨て札に入れず、ゲームから取り除く（山札にスープを混ぜないため）
- 冷え込みによる体温低下・凍死判定は席0から席順に処理する
- CPUの燃料選択で「火力7への近さ」が同じときは、小さい燃料 → 湿った木を優先

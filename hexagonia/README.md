# ヘキサゴニア（仮） (hexagonia)

六角形のマスでセル（領土）を広げ、強化し、相手のセルを破壊して争う陣取りゲームです。2〜12人でオンライン対戦できます。

- オンライン対戦は [PeerJS](https://peerjs.com/)（WebRTC の P2P）を使います。部屋を作った人（ホスト）のブラウザがゲームを進め、サーバーはいりません
- 各プレイヤーは別々の端末・ブラウザから参加します（PC・スマホ・タブレット対応）
- 部屋の空いた席に CPU を入れられます。「CPUと遊ぶ」なら、ひとりで通信なしでも遊べます
- ビルドは不要です。素の HTML・CSS・JavaScript だけでできています
- ゲーム名はまだ決まっていないので、仮の名前です

---

## 遊び方

### 公開する（GitHub Pages）

1. GitHub でこのリポジトリを開き、「Settings」→「Pages」を開く
2. 「Build and deployment」の Source を「Deploy from a branch」にする
3. Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 数分待つと `https://（ユーザー名）.github.io/minigame_by_claude/` のような URL が出ます。その後ろに `hexagonia/` を付けた URL がゲームのページです

> 手元で試すときは、このフォルダで `python3 -m http.server` などを動かして `http://localhost:8000/` を開いてください。

### 部屋を作る・参加する

1. ホストが名前を入れて「部屋を作る」を押す
2. ロビーに出る「部屋ID」か「招待URL」をほかの人に送る
3. 参加する人は招待URLを開くか、部屋IDを入れて「参加する」を押す
4. ロビーで陣営色（12色）を選ぶ
5. 人数が足りないときは、ホストが「＋ CPUを追加」で CPU を入れる（「外す」で外せる）
6. 必要なら、ホストが「盤面の大きさ（直径）」を選ぶ（自動・7・9・11・13・15マス）
7. 2〜12人そろったら、ホストが「ゲーム開始」を押す

### ひとりで遊ぶ（CPU対戦）

トップの「CPUと遊ぶ（ひとりで・通信なし）」を押すと、CPU 1人が入ったロビーになります。CPU は3人まで増やせます。通信はしないので、インターネットにつながっていなくても遊べます。

### 注意

- **ホストはゲームが終わるまでページを閉じたり再読み込みしたりしないでください**。ホストのページを閉じると部屋が終わります（閉じようとすると確認が出ます）。スマホでホストをするときは、スリープや別アプリへの切り替えにも気をつけてください
- ホスト以外の人は、接続が切れても同じブラウザで招待URLを開き直して「参加する」を押せば、同じプレイヤーとして戻れます
- 人数が多いとき（とくに10人以上）は、ホストのブラウザが全員分の通信をこなすので、PCでホストをするのがおすすめです
- 1台で試すときは、ホストとは別のブラウザかシークレットウィンドウで参加してください（同じブラウザだと同じプレイヤーとみなされます）
- 接続の仲介に PeerJS の無料公開サーバー（0.peerjs.com）を、ライブラリの読み込みに cdnjs を使います。公開サーバーが混んでいたり、会社・学校のネットワークなどではつながらないことがあります（TURN サーバーは使っていません）

## ルール

### 準備

- 盤面は大きな六角形です。大きさはふつう人数に合わせて決まります（2人：直径7／3人：9／4人：11／5〜6人：13／7〜8人：15／9〜12人：17）。ロビーでホストが直径 7〜21マスから選ぶこともできます
- **川** が、隣り合うコアのあいだを流れます（人数分）。4人までは盤面の中心から外側まで流れて陣地を区切り、5人以上は外側の半分くらいだけ流れます（中心は開いている）。コアとその周りには流れません
- 残りのマスの地形（平原・山岳・鉱山）はランダムに置かれます（割合は 平原70%：山岳15%：鉱山15%）。各コアとその周り1マスは平原に固定です
- 各プレイヤーのコア（未強化）は盤面の一番外側に等間隔に置かれます。全員が同じ条件になるよう、2〜3人では全員が角（隣のマス3つ）、4人では全員が辺（隣のマス4つ）に置かれます
- 全員、資源トークン3個から始めます（攻撃・防御トークンは0個）。手番順はランダムです

### 手番

自分の手番では行動を **最大3回** 行い、「手番終了」で資源を受け取って次の人へ回します。
3回使い切ると、画面中央に「手番終了」と「行動 +1」が出ます。**資源を払うと、その手番の行動回数を1回増やせます**。必要な資源は6個から始まり、同じ手番で増やすたびに +4（6 → 10 → 14…）。手番が変わると6個に戻ります。
資源が足りないなどで、もうできる行動がなくなったら（行動 +1 も買えないとき）、自動で手番終了になります。
持ち時間は **120秒**（7人以上は **60秒**）です。切れると自動で手番終了になります（破壊の攻防のあいだは止まります）。

| 行動 | 資源 | 内容 |
| --- | --- | --- |
| 拡張 | 1（山岳マスは2、川マスは4） | 自分のセルに隣接する空きマスに、未強化セルを置く。山岳マスなら防御トークン +1。川マスへの拡張は「橋をかける」 |
| 強化 | 2 | 自分の未強化セル1つを強化済にする。攻撃トークン +1。山岳マスなら防御トークン +1 も |
| 強化（防御済へ） | 3 | 自分の強化済セル1つを **防御済** にする（3段階目）。防御済のセルは、攻撃が2回成功しないと落ちない |
| 破壊 | 1 | 自分のセルに隣接する相手セル1つを破壊しようとする（下の「破壊の攻防」）。成功すると、そのマスがそのまま自分のセルになる |
| 補強 | 2 | 防御トークン +1・攻撃トークン +1 |

### 手番終了時の資源

- 強化済セル1つにつき +1
- 鉱山マスのセルは、強化しなくても +1、強化すると +2
- コアは状態に関係なく常に +2（強化済ならさらに +1）

### 維持費

- 手番終了時、資源を受け取ったあとに **維持費** を払います
- 維持費は「セルの数 ÷ 4（切り捨て）」。**平原のセルは半分** として数えます（例：平原8つで1、山岳4つで1）
- 払えないときは、持っている資源を全部払い、**足りない資源1つにつきセルを1つ** 選んで捨てます（コアは捨てられません）。捨てたマスは空きマスに戻ります
  - 画面中央にパネルが出るので、盤面で捨てるセルをタップして「このセルを捨てる」。「おまかせで選ぶ」もあります
  - 30秒で決めなければ、自動で選びます（一番大きなかたまりから外れたセル、未強化、コアから遠いものから）

### 川と橋

- 川マスにはそのままではセルを置けません。自分のセルの隣の川マスに、資源4で **橋をかける** と、自分のセルになります
- 橋はふつうのセルと同じく、かたまりのつながりに数え、強化もできます（維持費は1つ分）
- 橋は破壊されると **落ちて川に戻ります**（攻撃側のセルにはなりません）。橋を落として、相手のかたまりを分断できます

### 破壊の攻防

1. 攻撃側が破壊を宣言し、資源を1払う
2. 攻撃側は攻撃トークンを、防御側は防御トークンを、それぞれ何個出すかを **伏せて** 決める（30秒以内。決めなければ0個）。相手が持っている数は見えるが、何個出すかは見えない
3. 2人とも決めたら同時に公開する。**攻撃 ≧ 防御なら破壊成功**、攻撃 ＜ 防御なら破壊失敗

- 出したトークンはすべてなくなります（成功・失敗にかかわらず）
- 防御側が防御トークンを1個も持っていなければ、出し合いなしでそのまま成功します。攻撃側が攻撃トークンを持っていなければ、攻撃側は0個に決まります
- 破壊に成功したマスは、そのまま攻撃側の未強化セルになります（行動回数・資源は使いません。山岳マスなら拡張と同じく防御トークン +1）。相手のコアを破壊したときも同じです

### 脱落と勝敗

- **防御済** のセル（コアや橋も）は、攻撃が1回成功しても落ちず、強化済に戻るだけです。もう一度成功すると破壊されます
- コアは、防御済でなければ攻撃が1回成功すると破壊されます
- コアを破壊されたプレイヤーは脱落します。セルはすべて空きマスに戻り、トークンもなくなります
- 自分以外の全員が脱落したら、その時点で勝利
- 12ラウンドが終わったら、**つながっている一番大きなかたまり**（隣り合う自分のセルのまとまり）が最も大きい人の勝利（同じなら同率優勝）。セルの総数ではないので、離れたところにあるセルは数に入りません。プレイヤー一覧の「⬡ 9/12」は「一番大きなかたまり 9 ／ セルの総数 12」です

## 画面と操作

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 拡大・縮小 | マウスホイール | 2本指でピンチ |
| 移動 | ドラッグ | 1本指でドラッグ |
| マスを選ぶ（行動のボタンを出す） | クリック | タップ・長押し |
| マスの情報 | マスにカーソルを合わせる | マスを選ぶと出る |
| 表示を戻す | 「全体表示」ボタン | 同左 |

- 自分の手番では、行動できるマスが薄く光ります
- マスを選ぶと、マスの左（入りきらないときは右）に半透明のツールチップが出て、そのマスでできる行動（空きマスなら拡張、自分の未強化セルなら強化、相手のセルなら破壊）のボタンが出ます。コストと得られるもの、できないときは理由も出ます。もう一度同じマスを選ぶか、盤面の外を選ぶか、Esc キーで閉じます
- マスに関係しない「補強」と「手番終了」は、右（スマホでは下）のパネルのボタンから
- 破壊を宣言されると、防御側の画面に「防御トークンを出す／出さない」が、防御されると攻撃側の画面に「攻撃トークンを出す／諦める」が出ます。何個出したかは全員の画面に表示されます
- 破壊の攻防では、攻撃側・防御側の画面に「−／＋」で出す数を決めるパネルが出ます。決めたかどうかは全員に見えますが、数は公開まで見えません。公開されると、全員の画面に出し合いの結果が少しのあいだ出ます
- 上の「持ち時間」に、手番の残り時間が出ます。自分の手番の残り10秒は時計の音が鳴ります
- 拡張・強化・破壊・脱落などで変化したマスは一瞬白く光ります（守られたマスは青く光ります）
- 効果音が鳴ります（自分の手番・拡張・強化・補強・破壊の宣言・成功・失敗・脱落・勝敗など）。音声ファイルは使わず、ブラウザで合成しています
- 「設定」で、色覚多様性に配慮した配色（Okabe-Ito 配色）に切り替えたり、陣営ごとにセルの縁の模様（実線・破線・二重線・点線）を変えたり、効果音を消したりできます。陣営色は12色。Okabe-Ito 配色は8色しかないので、9人以上のときは縁の模様を自動で組み合わせて見分けられるようにします

### しくみ（ホスト権威型）

- ホストのブラウザで `Room` を動かします。盤面の生成（地形のランダム配置）もホストが行います
- 参加者は行動の要求（`{ type: 'act', action }`）をホストへ送り、ホストが `engine.js` でルール上可能かを確かめてから状態を更新し、全員に最新の状態を配信します
- 状態は 16KB を超えることがあるので、PeerJS の `binary` シリアライズ（大きなメッセージを分割して送れる）を使っています
- CPU はホストのブラウザの `Room` の中で動きます。CPU の番になると、少し間をおいて（行動は約0.9秒、攻防の応答は約0.7秒）1手ずつ打ちます。「CPUと遊ぶ」では同じ `Room` を通信なしで動かします
- 参加者は3秒ごとに生存確認を送り、20秒返事がなければ切断扱いになります
- ファイルを更新したら、`index.html` の `?v=` の数字を上げてください。GitHub Pages ではブラウザが古いファイルを最大10分ほど使い回すので、上げ忘れると新しい `index.html` と古い `client.js` が混ざって動かないことがあります
- テスト用に `window.HEXAGONIA_P2P` を先に定義すると、PeerJS の読み込み元と接続先（自前の PeerServer など）を差し替えられます

| 切断した人の手番 | 30秒待っても戻らなければ手番終了。攻防で数を決めていなければ、30秒で0個。戻ってくれば続けて遊べる |

### 仕様書に書かれていなかった点の扱い

- コアの周りで盤面の外になるマスはない扱い（コアは盤面の一番外側にある）
- 破壊できるのは相手のコアを含むすべてのセル。コアも強化できる
- 12ラウンドの終了時に脱落している人は順位に入らない
- ゲーム終了後、ホストが「ロビーに戻る」を押すと、同じメンバーで次のゲームを始められる
- 黄色は山吹色寄り（`#E39B00`）にして、半透明でも薄くならないようにした

### CPU の考え方

- 人間と同じ公開情報（盤面・全員のトークン数）だけで考えます
- 手番では、できる行動それぞれに点数を付けて一番高いものを選び、よい行動がなくなったら手番終了します
  - 破りきれる相手のコアがあれば最優先で破壊
  - 序盤〜中盤はコアや鉱山マスのセルの強化（資源が増える）と、鉱山マス・相手の方向への拡張を重視
  - 自分のコアの近くに相手のセルが来たら補強し、コアの隣の相手セルは優先して破壊
  - 防御済にするのは、狙われそうなコアと、相手と接している前線のセル・橋だけ
  - 一番大きなかたまりにつながる拡張を重視し、終盤（残り2ラウンド）は特に重視。首位の人のかたまりを削る破壊も狙う
  - 行動回数を使い切ったら、資源を払ってでもやりたい行動（点数が高い行動）があるときだけ行動 +1 を買う
  - 橋は、向こう側に新しく取れる土地があるときだけかける
  - 維持費で資源が増えなくなってきたら広げるのを控える（平原は控えめに）。セルを捨てるときは、一番大きなかたまりから外れたセル・未強化・コアから遠いものから
- 攻防では、相手が持っている数を見て出す数を決めます
  - 攻撃側：相手が防御トークンを全部出しても破れるなら、ちょうどその数。破れないときは、コアなら全部、ほかは読み合いで全部か少なめ
  - 防御側：相手が攻撃トークンを全部出しても守れる数を出す（コアのための分は残す）。足りないときは、コアなら全部、ほかは出さないか少しだけ

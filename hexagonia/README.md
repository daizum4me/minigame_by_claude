# ヘキサゴニア (hexagonia)

六角形のマスでセル（領土）を広げ、強化し、相手のセルを破壊して争う陣取りゲームです。2〜12人でオンライン対戦できます。

- オンライン対戦は [PeerJS](https://peerjs.com/)（WebRTC の P2P）を使います。部屋を作った人（ホスト）のブラウザがゲームを進め、サーバーはいりません
- 各プレイヤーは別々の端末・ブラウザから参加します（PC・スマホ・タブレット対応）
- 部屋の空いた席に CPU を入れられます。「CPUと遊ぶ」なら、ひとりで通信なしでも遊べます
- ビルドは不要です。素の HTML・CSS・JavaScript だけでできています

---

## 遊び方

### 公開する（GitHub Pages）

1. GitHub でこのリポジトリを開き、「Settings」→「Pages」を開く
2. 「Build and deployment」の Source を「Deploy from a branch」にする
3. Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 数分待つと `https://（ユーザー名）.github.io/minigame_by_claude/` のような URL が出ます。その後ろに `hexagonia/` を付けた URL がゲームのページです

> 手元で試すときは、このフォルダで `python3 -m http.server` などを動かして `http://localhost:8000/` を開いてください。

### 部屋を作る・参加する

1. ホストが名前を入れて「部屋を作る」を押す
2. ロビーに出る「部屋ID」か「招待URL」をほかの人に送る
3. 参加する人は招待URLを開くか、部屋IDを入れて「参加する」を押す
4. ロビーで陣営色（12色）を選ぶ
5. 人数が足りないときは、ホストが「＋ CPUを追加」で CPU を入れる（「外す」で外せる）
6. 必要なら、ホストが「盤面の大きさ（直径）」を選ぶ（自動・7・9・11・13・15マス）
7. 2〜12人そろったら、ホストが「ゲーム開始」を押す

### ひとりで遊ぶ（CPU対戦）

トップの「CPUと遊ぶ（ひとりで・通信なし）」を押すと、CPU 1人が入ったロビーになります。CPU は3人まで増やせます。通信はしないので、インターネットにつながっていなくても遊べます。

### 注意

- **ホストはゲームが終わるまでページを閉じたり再読み込みしたりしないでください**。ホストのページを閉じると部屋が終わります（閉じようとすると確認が出ます）。スマホでホストをするときは、スリープや別アプリへの切り替えにも気をつけてください
- ホスト以外の人は、接続が切れても同じブラウザで招待URLを開き直して「参加する」を押せば、同じプレイヤーとして戻れます
- 人数が多いとき（とくに10人以上）は、ホストのブラウザが全員分の通信をこなすので、PCでホストをするのがおすすめです
- 1台で試すときは、ホストとは別のブラウザかシークレットウィンドウで参加してください（同じブラウザだと同じプレイヤーとみなされます）
- 接続の仲介に PeerJS の無料公開サーバー（0.peerjs.com）を、ライブラリの読み込みに cdnjs を使います。公開サーバーが混んでいたり、会社・学校のネットワークなどではつながらないことがあります（TURN サーバーは使っていません）

## ルール

### 準備

- 盤面は大きな六角形です。大きさはふつう人数に合わせて決まります（2人：直径7／3人：9／4人：11／5〜6人：13／7〜8人：15／9〜12人：17）。ロビーでホストが直径 7〜21マスから選ぶこともできます
- **河川** は、対等さより自然さを重視して置かれます。本流が盤面の端から反対側の端へ曲がりくねって流れ、盤面が大きいと支流（半径8以上で1本）が本流に合流します。コアとその周りには流れません。どのコアも、河川を渡らずに十分な広さの島（盤面のマス数 ÷ 人数 の 3/5 以上）を持てない配置になったら作り直します（何度やってもだめなら河川なし。`RULES.islandShare`）
- 残りのマスの地形は、平原 約73%・**鉱山（◆）**・**農地（●）**・**森林（▽）** 約9%ずつです。効果のあるマスは合わせて約27%で、3種類に均等に分けます（`RULES.terrainRatio` で変えられます）
  - 公平さのため、どのコアにも、距離2（足りなければ3）のマスに3種類が1つずつ必ずあります
  - それとは別に、空きマスの少なくとも10%を効果のあるマスとして散らします。散らすマスは **盤面の中心に近いほど出やすく**（中心からの距離に応じて3乗で重みづけ。`RULES.centerShare`・`RULES.centerBias`）、真ん中ほど豊かな土地になります。そのため、効果のあるマスは全体で約3割になります
  - 鉱山マス：拡張したとき（破壊で取ったときも）と強化したときに、戦力トークン +1
  - 農地マス：このセルがあると、手番終了時に食料 +1（強化でもらえる食料 +1 とは別）
  - 森林マス：このセルがあると、手番終了時に資源 +1（強化でもらえる資源 +1 とは別）
- 各プレイヤーのコア（未強化）は、6人までは盤面の一番外側に等間隔に置かれます（全員が角、または全員が辺になるようにそろえる）。7人以上は外側だけだと窮屈なので、約3分の1のコアを内側の輪（中心と外周のあいだくらい）に置きます
- 全員、資源トークン3個・**戦力トークン**2個から始めます（食料は0個）。手番順はランダムです
- 戦力トークンは、破壊で攻めるときにも、破壊から守るときにも使います
- **ほかの人の戦力トークンの数は見えません**（自分の分と、資源・食料の数は見えます）

### 手番

手番の順はゲームのあいだ変わりません（ラウンドが変わってもずらしません）。脱落した人は飛ばします。

7人以上で、内側にコアがある人は、ラウンド1の前に **1手番ずつ先に** 動けます（先行）。

自分の手番では、決まった回数まで行動し、「手番終了」で資源を受け取って次の人へ回します。行動回数とラウンド数は人数に合わせて自動で決まります（ロビーでホストが変えることもできます）。

| 人数 | 行動回数 | ラウンド数 |
| --- | --- | --- |
| 2〜4人 | 3 | 12 |
| 5〜6人 | 4 | 10 |
| 7〜8人 | 4 | 8 |
| 9〜12人 | 5 | 6 |
3回使い切ると、画面中央に「手番終了」と「行動 +1」が出ます。**資源を払うと、その手番の行動回数を1回増やせます**。必要な資源は6個から始まり、同じ手番で増やすたびに +4（6 → 10 → 14…）。手番が変わると6個に戻ります。
資源が足りないなどで、もうできる行動がなくなったら（行動 +1 も買えないとき）、自動で手番終了になります。
持ち時間は **120秒**（7人以上は **60秒**）です。切れると自動で手番終了になります。破壊の攻防のあいだも止まりません（攻防中に切れたら、攻防が終わってから手番終了）。

| 行動 | 資源 | 内容 |
| --- | --- | --- |
| 拡張 | 1（河川マスは3） | 自分のセルに隣接する空きマスに、未強化セルを置く。河川マスへの拡張は「橋をかける」 |
| 強化 | 2 | 自分の未強化セル1つを強化済にする。**戦力トークン +1**。強化済のセルは拠点になる（下の「拠点」） |
| 破壊 | 2（戦力トークン1個以上が必要） | **自分の強化済のセルに隣接する**相手セル1つを破壊しようとする（下の「破壊の攻防」）。成功すると、そのマスがそのまま自分のセルになる |
| 生産 | 2 | 戦力トークン +1。**行動回数を使わない**（使い切っていてもできる）。**ログには出ない**（戦力トークンの数をわかりにくくするため） |

### 手番終了時の資源

- 強化済セル1つにつき +1
- 森林マスのセルは +1（強化とは別。強化済の森林は +2）
- コアは常に +2（強化済ならさらに +1）

### 食料（黄色の丸）

- 手番終了時に、食料を作ってから食べます
  - 作る：コア **+6**、強化済のセル（コアも）1つにつき **+1**、農地マスのセル1つにつき **+1**
  - 食べる：**セル1つにつき1**（コアや橋も1マスとして数える）
- 余った食料は持ち越して貯まります。ほかの人の食料の数も見えます
- 足りないときは、足りない数だけセルを選んで捨てます（コアは捨てられません。30秒で決めなければ自動で選びます）。手番終了ボタンに「食料 +8 −10（2 足りない）」のように出るので、手番を終える前にわかります

### セルを捨てる

- 食料が足りないときは、画面中央にパネルが出るので、盤面で捨てるセルをタップして「このセルを捨てる」。「おまかせで選ぶ」もあります
- 30秒で決めなければ、自動で選びます（一番大きなかたまりから外れたセル、未強化、コアから遠いものから）。捨てたマスは空きマスに戻ります

### イベント

- ラウンドの始まりに **1/3** の確率で、次のどれか1つが起きて、そのラウンドの間続きます
- 予告はありません。起きたイベントは画面上部とログに出ます

| マイナス | プラス |
| --- | --- |
| 不作：食料生産が0.5倍 | 豊作：食料生産が1.5倍 |
| 枯渇：資源生産が0.5倍 | 発見：資源生産が1.5倍 |
| 洪水：河川の隣のセル1つにつき食料 −1（食べる量が増える） | 豊漁：河川の隣のセル1つにつき食料 +1 |
| 疫病：行動可能回数 −1 | 祭事：行動可能回数 +1 |

- 倍率の端数は切り捨て。「河川の隣のセル」に橋は数えません。行動回数は1回より少なくなりません
- 7人以上の先行（ラウンド1の前の手番）にはイベントはありません
- 先のラウンドのイベントはホストのブラウザだけが持ち、ほかの人には今と次のラウンドの分だけを送ります

### 河川と橋

- 河川マスにはそのままではセルを置けません。自分のセルの隣の河川マスに、資源3で **橋をかける** と、自分のセルになります
- 橋はふつうのセルと同じく、かたまりのつながりに数え、強化もできます
- 橋は破壊されると **落ちて河川に戻ります**（攻撃側のセルにはなりません）。橋を落として、相手のかたまりを分断できます

### 拠点（どこを強化するか）

- **拠点**：破壊できるのは、自分の強化済のセル（強化済のコアも）に隣接する相手のセルだけです。攻めたい方向のセルを強化します
- 前線に強化すれば攻めの足がかりになります。後方に強化すれば安全に稼げますが、攻めには使えません
- 以前あった「城壁」（強化済のセルの隣のセルを守る側に +1）は、攻めが弱すぎたのでなくしました

### 破壊の攻防

1. 攻撃側が破壊を宣言し、資源を2払う（戦力トークンを1個以上持っていないと宣言できない）
2. 攻撃側は戦力トークンを **1個以上**、防御側は0個以上、それぞれ何個出すかを **伏せて** 決める（30秒以内。決めなければ攻撃側は1個・防御側は0個）。おたがいの戦力トークンの数は見えない
3. 2人とも決めたら判定する。**攻撃側 ≧ 防御側なら破壊成功**（**同じ数なら攻撃側の勝ち**）、攻撃側 ＜ 防御側なら守られる。**全員に知らされるのは成功か失敗かだけ**で、出した数は当人にしかわかりません

- 出したトークンはすべてなくなります（成功・失敗にかかわらず）
- 攻撃側は、決着する前なら破壊を取りやめられます（攻防のパネルの「破壊をやめる」）。資源と行動回数は戻り、トークンは減りません。何回でもできます（攻防のあいだも持ち時間は進むので、引き延ばしにはなりません）
- 防御側が戦力トークンを1個も持っていなくても攻防になり、防御側は（0個を）選びます。持っていないことが相手に伝わらないようにするためです。攻撃側の戦力トークンが1個しかなければ、1個に決まります
- 攻めに使った戦力トークンはなくなるので、そのぶん守りに使える数が減ります
- 破壊に成功したマスは、そのまま攻撃側の未強化セルになります（行動回数・資源は使いません。鉱山マスなら拡張と同じく戦力トークン +1）。相手のコアを破壊したときも同じです

### 脱落と勝敗

- コアは、攻撃が1回成功すると破壊されます
- コアを破壊されたプレイヤーは脱落します。**コアを破壊した人が、セル（強化済のものはそのまま。コアだったマスは攻撃側のセルに）と、資源・戦力・食料をまるごと奪います**。倒すほど強くなるので、終盤に一気に決着しやすくなります
- 切断したまま戻らない人をホストが脱落させたときは、セルは空きマスに戻り、トークンもなくなります
- 自分以外の全員が脱落したら、その時点で勝利
- 最後のラウンドが終わったら、**つながっている一番大きなかたまり**（隣り合う自分のセルのまとまり）が最も大きい人の勝利（同じなら同率優勝）。セルの総数ではないので、離れたところにあるセルは数に入りません。プレイヤー一覧の「⬡ 9/12」は「一番大きなかたまり 9 ／ セルの総数 12」です

## 画面と操作

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 拡大・縮小 | マウスホイール | 2本指でピンチ |
| 移動 | ドラッグ | 1本指でドラッグ |
| マスを選ぶ（行動のボタンを出す） | クリック | タップ・長押し |
| マスの情報 | マスにカーソルを合わせる | マスを選ぶと出る |
| 表示を戻す | 「全体表示」ボタン | 同左 |
| 行動があったマスを追う | 「◎ フォーカス」ボタン（設定でも切り替え可） | 同左 |

- 自分の情報（トークン・残り行動）と「生産」「手番終了」のボタンは、盤面の下に浮かんだバーにあります。右（スマホでは下）のパネルには、プレイヤー一覧とログがあります
- 自分の手番では、行動できるマスが薄く光ります
- マスを選ぶと、マスの左（入りきらないときは右）に半透明のツールチップが出て、そのマスでできる行動（空きマスなら拡張、自分の未強化セルなら強化、相手のセルなら破壊）のボタンが出ます。コストと得られるもの、できないときは理由も出ます。行動のボタンはマスと同じ高さに来ます。ツールチップのボタン以外の部分をクリックすると、マスの反対側に移ります（下のマスを選びやすくするため）。もう一度同じマスを選ぶか、盤面の外を選ぶか、Esc キーで閉じます
- マスに関係しない「生産」と「手番終了」は、盤面の下のバーのボタンから
- 破壊の攻防では、攻撃側・防御側の画面に「−／＋」で出す数を決めるパネルが出ます。決めたかどうかは全員に見えますが、数は公開まで見えません。公開されると、全員の画面に出し合いの結果が少しのあいだ出ます
- 上の「持ち時間」に、手番の残り時間が出ます。自分の手番の残り10秒は時計の音が鳴ります
- 拡張・強化・破壊・脱落などで変化したマスは一瞬白く光ります（守られたマスは青く光ります）
- **チャット**：ロビーとゲーム中、画面の左下に浮かせた欄で参加者全員と話せます（自分の情報のバーと重なる幅では、バーのすぐ上に出ます）。見出しを押すと開け閉めでき、閉じているあいだは未読の数と、ほかの人の発言がお知らせに出ます。PC は開いた状態、スマホは閉じた状態から始まり、前回の状態を覚えます。1件80文字まで、直近30件を残します（ロビーからゲームまで続けて残る）
- 効果音が鳴ります（自分の手番・拡張・強化・生産・破壊の宣言・成功・失敗・脱落・勝敗など）。音声ファイルは使わず、ブラウザで合成しています
- 「設定」で、色覚多様性に配慮した配色（Okabe-Ito 配色）に切り替えたり、陣営ごとにセルの縁の模様（実線・破線・二重線・点線）を変えたり、効果音を消したりできます。陣営色は12色。Okabe-Ito 配色は8色しかないので、9人以上のときは縁の模様を自動で組み合わせて見分けられるようにします

### しくみ（ホスト権威型）

- ホストのブラウザで `Room` を動かします。盤面の生成（地形のランダム配置）もホストが行います
- 参加者は行動の要求（`{ type: 'act', action }`）をホストへ送り、ホストが `engine.js` でルール上可能かを確かめてから状態を更新し、全員に最新の状態を配信します
- 状態は 16KB を超えることがあるので、PeerJS の `binary` シリアライズ（大きなメッセージを分割して送れる）を使っています
- CPU はホストのブラウザの `Room` の中で動きます。CPU の番になると、少し間をおいて（行動は約0.9秒、攻防の応答は約0.7秒）1手ずつ打ちます。「CPUと遊ぶ」では同じ `Room` を通信なしで動かします
- 参加者は3秒ごとに生存確認を送り、20秒返事がなければ切断扱いになります
- ファイルを更新したら、`index.html` の `?v=` の数字を上げてください。GitHub Pages ではブラウザが古いファイルを最大10分ほど使い回すので、上げ忘れると新しい `index.html` と古い `client.js` が混ざって動かないことがあります
- テスト用に `window.HEXAGONIA_P2P` を先に定義すると、PeerJS の読み込み元と接続先（自前の PeerServer など）を差し替えられます

### CPU の考え方

- 強さは **よわい・ふつう・つよい** の3段階で、ホストがロビーで CPU ごとに選べます（最初は「ふつう」。チュートリアルの相手は「よわい」）
  - よわい：気まぐれに行動を選び、早めに手番を終え、行動 +1 を買わず、攻防で出す数もでたらめ
  - ふつう：下の考え方のとおり
  - つよい：迷いが少なく、強化を多め・拡張を控えめにする（CPU どうしの対戦で一番勝てた打ち方）。ふつうを相手にすると、2人戦で約6〜7割、4人戦で約5割勝つ

- 人間と同じ公開情報（盤面・全員のトークン数）だけで考えます
- 手番では、できる行動それぞれに点数を付けて一番高いものを選び、よい行動がなくなったら手番終了します
  - 破りきれる相手のコアがあれば最優先で破壊。破りきれなくても、コアは読み合いで狙う
  - 相手のコアの方向へ広げることを重視する（コアを破壊すれば、相手のセルとトークンをまるごと奪えるため）
  - 序盤〜中盤はコアや鉱山マスのセルの強化（資源が増える）と、鉱山マス・相手の方向への拡張を重視
  - 強化する場所は、新しく破壊できるようになる相手のセル（拠点）が多いところを重視。相手のコアの隣に拠点を作れるなら大きく重視し、そのあとはコアを破りきれる数まで戦力トークンをためる
  - 相手の戦力トークンを（見積もりで）破りきれないときは、破壊を控える（守る側はためた数を全部使えるため）
  - 自分のコアの近くに相手のセルが来たとき、戦力トークンがなく前線があるときは、戦力トークンを生産する。コアの隣の相手セルは優先して破壊
  - 一番大きなかたまりにつながる拡張を重視し、終盤（残り2ラウンド）は特に重視。首位の人のかたまりを削る破壊も狙う
  - 行動回数を使い切ったら、資源を払ってでもやりたい行動（点数が高い行動）があるときだけ行動 +1 を買う
  - 橋は、向こう側に新しく取れる土地があるときだけかける
  - 食べさせきれないなら広げない。セルを捨てるときは、一番大きなかたまりから外れたセル・未強化・コアから遠いものから
- 攻防では、相手が持っている数を見て出す数を決めます
  - 攻撃側：相手が（見積もりで）全部出しても破れるなら、それより1個多い数。破れないときは、コアなら全部、ほかは読み合いで全部か少なめ
  - 防御側：相手が（見積もりで）全部出しても守れる数を出す（コアのための分は残す）。足りないときは、コアなら全部、ほかは出さないか少しだけ
- 戦力トークンの数は見えないので、CPU は相手の数を実際には見ずに見積もります（最初の2個と、見えている増え方〔強化・鉱山〕から、攻防で少なくとも出したはずの数を引き、見えない生産の分を1個足す）

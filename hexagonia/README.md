# ヘキサゴニア（仮） (hexagonia)

六角形のマスでセル（領土）を広げ、強化し、相手のセルを破壊して争う陣取りゲームです。2〜4人でオンライン対戦できます。

- オンライン対戦は [PeerJS](https://peerjs.com/)（WebRTC の P2P）を使います。部屋を作った人（ホスト）のブラウザがゲームを進め、サーバーはいりません
- 各プレイヤーは別々の端末・ブラウザから参加します（PC・スマホ・タブレット対応）
- ビルドは不要です。素の HTML・CSS・JavaScript だけでできています
- ゲーム名はまだ決まっていないので、仮の名前です

---

## 遊び方

### 公開する（GitHub Pages）

1. GitHub でこのリポジトリを開き、「Settings」→「Pages」を開く
2. 「Build and deployment」の Source を「Deploy from a branch」にする
3. Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 数分待つと `https://（ユーザー名）.github.io/minigame_by_claude/` のような URL が出ます。その後ろに `hexagonia/` を付けた URL がゲームのページです

> 手元で試すときは、このフォルダで `python3 -m http.server` などを動かして `http://localhost:8000/` を開いてください。

### 部屋を作る・参加する

1. ホストが名前を入れて「部屋を作る」を押す
2. ロビーに出る「部屋ID」か「招待URL」をほかの人に送る
3. 参加する人は招待URLを開くか、部屋IDを入れて「参加する」を押す
4. ロビーで陣営色（赤・青・緑・黄）を選ぶ
5. 2〜4人そろったら、ホストが「ゲーム開始」を押す

### 注意

- **ホストはゲームが終わるまでページを閉じたり再読み込みしたりしないでください**。ホストのページを閉じると部屋が終わります（閉じようとすると確認が出ます）。スマホでホストをするときは、スリープや別アプリへの切り替えにも気をつけてください
- ホスト以外の人は、接続が切れても同じブラウザで招待URLを開き直して「参加する」を押せば、同じプレイヤーとして戻れます
- 1台で試すときは、ホストとは別のブラウザかシークレットウィンドウで参加してください（同じブラウザだと同じプレイヤーとみなされます）
- 接続の仲介に PeerJS の無料公開サーバー（0.peerjs.com）を、ライブラリの読み込みに cdnjs を使います。公開サーバーが混んでいたり、会社・学校のネットワークなどではつながらないことがあります（TURN サーバーは使っていません）

## ルール

### 準備

- 盤面は大きな六角形です。人数で大きさが変わります（2人：半径4・61マス／3人：半径5・91マス／4人：半径6・127マス）
- 地形（平原・山岳・鉱山）はランダムに置かれます（割合は 6：2：2）。各コアとその周り1マスは平原に固定です
- 各プレイヤーのコア（未強化）は外周寄りに等間隔に置かれます
- 全員、資源トークン3個から始めます（攻撃・防御トークンは0個）。手番順はランダムです

### 手番

自分の手番では行動を **最大3回** 行い、「手番終了」で資源を受け取って次の人へ回します。

| 行動 | 資源 | 内容 |
| --- | --- | --- |
| 拡張 | 1（山岳マスは2） | 自分のセルに隣接する空きマスに、未強化セルを置く。山岳マスなら防御トークン +1 |
| 強化 | 2 | 自分の未強化セル1つを強化済にする。攻撃トークン +1。山岳マスなら防御トークン +1 も |
| 破壊 | 1 | 自分のセルに隣接する相手セル1つを破壊しようとする（下の「破壊の攻防」） |
| 補強 | 2 | 防御トークン +1 |

### 手番終了時の資源

- 強化済セル1つにつき +1（鉱山マスの強化済セルはさらに +1）
- コアは状態に関係なく常に +2（強化済ならさらに +1）

### 破壊の攻防

1. 攻撃側が破壊を宣言し、資源を1払う
2. 防御側は防御トークンを1個出すか、出さないかを選ぶ。出さなければ（または0個なら）破壊成功
3. 防御側が出したら、攻撃側は攻撃トークンを1個出すか、諦めるかを選ぶ。出したら防御トークン1個が破壊されて 2 に戻る。諦めたら（または0個なら）破壊失敗

出したトークンはすべてなくなります。破壊されたセルは空きマスに戻ります。

### 脱落と勝敗

- コアを破壊されたプレイヤーは脱落します。セルはすべて空きマスに戻り、トークンもなくなります
- 自分以外の全員が脱落したら、その時点で勝利
- 12ラウンドが終わったら、セルの数が最も多い人の勝利（同数は同率優勝）

## 画面と操作

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 拡大・縮小 | マウスホイール | 2本指でピンチ |
| 移動 | ドラッグ | 1本指でドラッグ |
| マスを選ぶ | クリック | タップ |
| マスの情報 | マスにカーソルを合わせる | マスを長押し（行動を選んでいないときはタップでも） |
| 表示を戻す | 「全体表示」ボタン | 同左 |

- 行動ボタンを押すと、その行動ができるマスが光ります。光ったマスを選ぶと実行します（Esc キーで選択を解除）
- 破壊を宣言されると、防御側の画面に「防御トークンを出す／出さない」が、防御されると攻撃側の画面に「攻撃トークンを出す／諦める」が出ます。何個出したかは全員の画面に表示されます
- 「設定」で、色覚多様性に配慮した配色（Okabe-Ito 配色）に切り替えたり、陣営ごとにセルの縁の模様（実線・破線・二重線・点線）を変えたりできます

### 見た目

| 要素 | 見た目 |
| --- | --- |
| 平原マス／山岳マス／鉱山マス | 濃いグレーの六角形（山岳は ▲、鉱山は ★） |
| セル（未強化） | 陣営色の半透明の六角形（下の地形マークが透ける） |
| セル（強化済） | 内側に一回り小さい六角形の線 |
| コア | 中心に陣営色の円。枠が太く、少し光る |
| 資源トークン | 半透明オレンジの六角柱 |
| 防御トークン | 半透明青の立方体 |
| 攻撃トークン | 半透明赤の六芒星柱 |

## 開発者向けメモ

### ファイル

| ファイル | 中身 |
| --- | --- |
| `shared/engine.js` | ルール（盤面の生成・行動の検証と実行・破壊の攻防・脱落・勝敗）。ルールの数値は先頭の `RULES` にまとめてある |
| `shared/room.js` | 部屋（ロビー・陣営色・ゲーム開始・行動の受け付け・切断の扱い）。ホストのブラウザで動く |
| `board.js` | 盤面の描画（canvas）と、拡大・縮小・移動・マスの選択・ツールチップ |
| `client.js` | 画面と通信（PeerJS）。トークンの絵や陣営色の定義もここ |
| `index.html` / `style.css` | 画面 |
| `test/` | テスト（`npm test`。Node.js 18 以上） |

### しくみ（ホスト権威型）

- ホストのブラウザで `Room` を動かします。盤面の生成（地形のランダム配置）もホストが行います
- 参加者は行動の要求（`{ type: 'act', action }`）をホストへ送り、ホストが `engine.js` でルール上可能かを確かめてから状態を更新し、全員に最新の状態を配信します
- 状態は 16KB を超えることがあるので、PeerJS の `binary` シリアライズ（大きなメッセージを分割して送れる）を使っています
- 参加者は3秒ごとに生存確認を送り、20秒返事がなければ切断扱いになります
- テスト用に `window.HEXAGONIA_P2P` を先に定義すると、PeerJS の読み込み元と接続先（自前の PeerServer など）を差し替えられます

### テスト

```
cd hexagonia
npm test
```

盤面の大きさ・コアの配置・地形、各行動のコストと効果、行動回数、資源の計算、破壊の攻防（防御しない・防御と攻撃の出し合い・トークン切れ）、脱落、12ラウンド終了と同率優勝、部屋の進行（色の選択・開始・ホストによる検証・切断と復帰）を確かめます。

### 仕様書で「要確認」だった点の暫定の扱い

| 項目 | 暫定の扱い |
| --- | --- |
| 強化済コアの資源 | コアの +2 に加えて、強化済セルとしての +1 も得る（合計 +3）。コアのマス自身も平原に固定 |
| 破壊の資源コスト | 成功・失敗にかかわらず返ってこない |
| 攻防の出し方 | 1個ずつ交互に出す |
| 手番の制限時間 | なし |
| 切断した人の手番 | 30秒待っても戻らなければ自動で進める（手番なら「手番終了」、防御を選ぶ番なら防御トークンがあれば出す、攻撃を選ぶ番なら諦める）。戻ってくれば続けて遊べる |
| 戻ってこない人 | ホストがプレイヤー一覧の「脱落させる」で脱落させられる |
| ロビーでの切断 | 部屋から外れる（入り直せる） |
| ホストの切断 | 部屋が終わる |
| タッチ端末のマス情報 | 長押しで表示（行動を選んでいないときはタップでも表示） |
| ゲーム名 | 仮に「ヘキサゴニア」 |

### 仕様書に書かれていなかった点の扱い

- コアは外周の1つ内側の輪に置く（周り1マスを平原にするため）
- 破壊できるのは相手のコアを含むすべてのセル。コアも強化できる
- 12ラウンドの終了時に脱落している人は順位に入らない
- ゲーム終了後、ホストが「ロビーに戻る」を押すと、同じメンバーで次のゲームを始められる
- 黄色は山吹色寄り（`#E39B00`）にして、半透明でも薄くならないようにした

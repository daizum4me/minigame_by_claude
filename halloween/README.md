# 🎃 ハロウィンお菓子ゲーム (halloween)

集落の家を1軒選んでお菓子をもらう、8人前後で遊ぶオンライン対戦ボードゲーム。
2人以上が同じ家に行くと誰ももらえない——高い家に行くか、被らない家に行くかの読み合いと、通話での嘘・駆け引きを楽しむゲームです。

- 👥 **オンライン対戦**：ルームを作って招待URLを送るだけ（アカウント登録なし）。2〜12人。空いた席にはCPUを入れられる
- 🤖 **CPU対戦**：ひとりでCPU（最大11人）と遊べる。通信なし
- 💬 ゲーム内チャット・スタンプ・📣行く家の宣言つき（通話に参加しない人も遊べる）
- 📱 スマホの縦画面でも遊べる

---

## 🚀 自分のパソコンで動かす

### 1. Node.js を入れる（最初の1回だけ）

[https://nodejs.org/ja](https://nodejs.org/ja) から **LTS版** をダウンロードしてインストールします。
入ったかどうかは、ターミナル（Windows は「PowerShell」、Mac は「ターミナル」）で次を打つと確認できます。

```
node -v
```

`v20.x.x` のように表示されればOK（18以上なら動きます）。

### 2. このフォルダで起動する

ターミナルで `halloween` フォルダに移動して、次の2行を打ちます。

```
cd halloween
npm install
npm start
```

`🎃 ハロウィンお菓子ゲーム: http://localhost:3000` と出たら、ブラウザで **http://localhost:3000** を開きます。
止めるときはターミナルで `Ctrl + C`。

> 同じWi-Fiにいる人なら、`http://（あなたのパソコンのIPアドレス）:3000` で参加できます。
> 遠くの友だちと遊ぶときは、次の「インターネットに公開する」を見てください。

### CPU対戦だけならサーバーなしでもOK

`index.html` をブラウザで直接開くだけで「🤖 CPUと遊ぶ」が使えます（オンライン対戦は使えません）。

## 🌐 インターネットに公開する（無料・Render を使う方法）

[Render](https://render.com/) という無料のサービスを使うと、友だちがURLを開くだけで遊べるようになります。
クレジットカードは不要です（2026年時点）。

1. **Render のアカウントを作る**
   [https://render.com/](https://render.com/) を開いて「Get Started」→「**GitHub**」でログインします（このリポジトリがあるGitHubアカウントで）。
2. **Web Service を作る**
   画面右上の「**+ New**」→「**Web Service**」を選び、一覧からこのリポジトリ（`minigame_by_claude`）を選んで「Connect」。
   GitHub の許可を求められたら、このリポジトリへのアクセスを許可します。
3. **設定を入力する**（ここが大事）

   | 項目 | 入れる値 |
   | --- | --- |
   | Name | 好きな名前（例：`halloween-candy`）。これがURLになります |
   | Branch | `main` |
   | Root Directory | `halloween` |
   | Runtime / Language | `Node` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |

4. 一番下の「**Deploy Web Service**」を押して数分待ちます。
   画面のログに `🎃 ハロウィンお菓子ゲーム` と出て、上のほうに `https://halloween-candy.onrender.com` のようなURLが出たら完成です。
5. そのURLを開いて「ルームを作る」→ 出てきた **招待URL** を友だちに送れば遊べます 🎉

### 知っておくと良いこと

- 無料プランは、15分ほど誰もアクセスしないと眠ります。次に開いたときは **起動に1分くらい** かかるので、遊ぶ前に一度開いておくと安心です。
- 眠ったり再起動したりすると、そのとき遊んでいたルームは消えます（データベースは使っていません）。
- GitHub の `main` ブランチを更新すると、Render が自動で新しい版に入れ替えます。

> **GitHub Pages で公開している場合**：GitHub Pages はサーバーを動かせないので、そこでは **CPU対戦だけ** 遊べます。
> Render のサーバーとつなぎたいときは `…/halloween/?server=https://halloween-candy.onrender.com` のように `server=` を付けて開きます。

## 🎮 遊び方

1. **トップ**：名前を入れて「ルームを作る」か、コードを入れて「コードで参加」。ひとりなら「CPUと遊ぶ」
2. **ロビー**：招待URLをコピーして友だちに送る。アイコンを選ぶ。ホストは設定の変更・CPUの追加・キック・「ゲーム開始」ができる
3. **ゲーム**（1ラウンドの流れ）
   - 🎃 **集落到着**：家のお菓子の量が見える。自分だけに 🔍ヒント（家1軒の本当の状態）が配られる
   - 💬 **作戦タイム**（120秒）：通話・チャットで話す。📣「ここに行く」と宣言できる（嘘OK）。全員が「スキップ」を押すとすぐ次へ
   - 🏠 **家を選ぶ**（30秒）：家をタップして「この家に決定」。時間切れはランダムな家へ
   - 📊 **結果**：全員の行き先と、訪問された家の状態が公開される
4. 9集落が終わったら、お菓子が一番多い人の勝ち。「もう一度遊ぶ」で同じメンバーのままロビーへ

詳しいルールはゲーム内の「📖 ルール説明」に載っています。

### 絵文字の意味

| 🏠 家 | 🍬 お菓子・普通 | 💰 お金持ち | 💤 留守 | 🧙‍♀️ 魔女 | 💥 衝突 | 🤚 奪取 | 👑 先頭 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 🔍 ヒント | 📜 ミッション | 📣 宣言 | ⏳ 残り時間 | 🎃 集落 | 🔌 切断中 | 🤖 CPU | |

### ミッション

| ミッション | 達成条件 | ボーナス |
| --- | --- | --- |
| 🎩 お客さん | お金持ちの家に訪問する（衝突してもOK） | +4 |
| 🔑 留守番 | 留守の家に訪問する（衝突してもOK） | +4 |
| 3️⃣ 3の家 | お菓子の量が3の家でお菓子をもらう | +2 |
| 2️⃣ 2の家 | お菓子の量が2の家でお菓子をもらう | +2 |
| 1️⃣ 1の家 | お菓子の量が1の家でお菓子をもらう | +2 |
| 🔁 常連さん | 同じ番号の家で2ラウンド連続お菓子をもらう | +4 |

## 🔌 接続が切れたとき

- 同じブラウザでページを開き直せば、同じプレイヤーとしてゲームに戻れます（ブラウザに保存した識別子で復帰）。
- 切断中の人はプレイヤー一覧に 🔌 が付きます。選ぶ時間には待たずにランダムな家へ行き、スキップの合意にも数えません。
- ロビーで30秒以上切断した人は、ルームから外れます。ホストが抜けたら次に古い参加者がホストになります。

## 🛠 開発者向けメモ

### ファイル

| ファイル | 中身 |
| --- | --- |
| `shared/config.js` | ルールの数値（設定の既定値・範囲、ミッション、絵文字など）。数値はすべてここ |
| `shared/engine.js` | 判定ロジック（家の抽選、ヒントの配り方、結果の計算、順位）。状態を持たない関数だけ |
| `shared/cpu.js` | CPUの考え方 |
| `shared/room.js` | ルーム（ロビー・フェーズ進行・タイマー・チャット・宣言・CPU・見せてよい情報の切り出し） |
| `server.js` | HTTP + WebSocket サーバー（`ws` パッケージ）。ルームはメモリ上に持つ |
| `index.html` / `style.css` / `client.js` | 画面（ビルド不要の素のHTML/CSS/JS） |
| `test/` | テスト（`npm test`） |

### しくみ

- 判定はすべてサーバーの `Room` が行い、各プレイヤーには `viewFor()` で **その人が見てよい情報だけ** を送ります。家の状態（公開前）・他人のヒント・他人のミッション・公開前の選択はブラウザに届きません（ミッションは最終結果で全員分を公開）。
- CPU対戦では同じ `Room` をブラウザの中で動かします（通信なし）。このときは自分のブラウザで動いているので、開発者ツールを使えば中身は見えます。
- CPUも人間と同じ情報（家のお菓子の量・自分のヒント・宣言・全員のお菓子の数・自分のミッション）だけで考えます。ほかの人も被りを避けて散らばる、と読んで家を選び、ときどき嘘の宣言やヒントの話もします。
- 環境変数 `PORT` で待ち受けるポートを変えられます（既定 3000）。`/health` は死活確認用。

### テスト

```
npm test
```

判定ロジック（魔女で衝突、先頭が複数、先頭のお菓子が少なくて奪いきれない、ミッション達成と魔女が同時、常連さん、ヒントの配り方など）と、ルームの進行（最後まで遊べる・秘密が送られない・時間切れ・切断・キック・ホストの引き継ぎ）を確かめます。

### 仕様書で決まっていなかった点の扱い

- 選ぶ時間の時間切れ・切断中の人は、ランダムな家を訪問する
- ミッション名は仕様書の仮の名前のまま。絵文字は 🎩🔑3️⃣2️⃣1️⃣🔁
- 奪取で先頭の残りが足りないときは、奪う人の順番をランダムに決めて先に奪った人から取る
- 結果の内訳の「家」は、魔女で0未満にならなかった分を差し引いた値（家＋奪取＋ミッション＝最終のお菓子）。ラウンド結果の表示では魔女の −5 をそのまま見せる
- 結果画面は約2.5秒の演出のあと「次へ」を押せる。10秒たつと自動で次へ
- キックとCPUの追加・削除はロビーでのみ。キックされた人は同じルームに戻れない
- 「もう一度遊ぶ」は誰が押してもルーム全員がロビーに戻る
- 名前の重複は末尾に 2, 3… を付ける。アイコンは他の人と同じものは選べない
- 人間が全員切断したルームは2分後に破棄する

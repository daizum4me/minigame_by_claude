# Cororo（オンライン対戦版）

駒を取らずに、押して盤の外へ落とす2人対戦ゲーム。相手の「玉」を押し出せば勝ちです。CPU戦・観戦・チュートリアルは元のまま、**2人でのオンライン対戦**を追加しています。

- 遊び方：`cororo/index.html` を開く（ビルド不要）。「部屋を作ってオンライン対戦」で部屋IDと招待URLができるので、相手に送ります。相手は部屋IDを入れて「参加する」（招待URLなら自動で入力されます）。
- 通信：PeerJS（WebRTC の P2P）。部屋を作った人がホストで、先手・後手と外周が落ちる順番を決めます。対局が終わるまでページを閉じないでください。
- どちらの画面でも、自分が下側・青（色は設定で変更可）で表示されます。手は相手の画面で180度回して反映します（盤は点対称）。
- 受け取った手は、ルール上合法かを確認してから反映します（ずれたときは画面に表示）。
- 再戦：両者が「再戦する」を押すと、先手と後手を入れ替えて始まります。
- 相手の接続が切れたら、あなたの勝ちとして終了します。
- 持ち時間：1手あたり2分（残り時間は上のバーに表示）。切れた側の負けです。
